# Blank Recall Engine

Blank recall is the center of HifzOS.

Modes:
- Pure blank recall (V1)
- Image hint recall (V2)
- Mushaf position hint (V2)
- Meaning hint (V2)
- Translation lock (V2)

V1 behavior:
- generate fill-gap prompt from ayah
- accept typed answer
- score correctness
- update weakness and review queue
