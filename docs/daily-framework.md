# Daily Framework

## Phase 1 — Wake System
Morning starts with Qur'an using an alarm challenge.

## Phase 2 — Repeat-to-Hear
Ear first, tongue second: listen then repeat cycles.

## Phase 3 — New Memorization
Small chunk method: 1 ayah, repeat, recall, connect.

## Phase 4 — Blank Recall
Core loop: answer from memory without passive reading.

## Phase 5 — Similarity Protection (deferred)
Guard against confusion in lookalike ayat.

## Phase 6 — Weak Ayah Detection
Track hesitation and mistakes into a live weakness list.

## Phase 7 — Night Repair
End day by fixing unstable ayat before sleep.
